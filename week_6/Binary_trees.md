# Binary Trees
    A classification of tree data structure,
    a binary tree is defined as one node cannot have more than 2 pointers to following nodes.

* A linked list is a one dimensional data structure
    * every node has a pointer to the next node

# Full and balanced trees
    A full tree is completely filled with nodes at its deepest level
    meaning every tree has atleast two children.

    Left and right subtrees heigh differ no more than one.

* The key to find if a tree is balanced is to check if left and right subtrees height differ no more than (+)(-) one


# Binary Search Trees

    A special kind of tree in which data is ordered
    Really efficient structure for storing ordered data
        O(log(n))
* Every node can have 0 - 2 children
* The data values of all descendants to the of any node are less than the data value stored in that node, and all descendants to the right have greater data values.
    * Thus, by definition BST's cannot have distinct keys (cant have more than one of the same value)
  
  
LEFT < THAN NODE VALUE.  
RIGHT > THAN NODE VALUE.


When sorting strings in BST's we use ASCI table to compare string values
